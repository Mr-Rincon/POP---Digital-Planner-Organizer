# POP - Digital Planner & Organizer

> Digital platform developed with HTML, CSS, JavaScript and PHP, designed as a tool to help people organize their schedule in calendar view, store passwords, contacts and bookmarks, create notes and reminders, sort items by category all under an account profile. This was a college final project graded A.
